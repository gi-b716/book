欢迎阅读《Rust 程序设计语言》，这是一本关于 Rust 的入门书籍。Rust 编程语言帮助你编写更快、更可靠的软件。在编程语言设计中，高级工程学和低级控制往往存在矛盾；Rust 试图挑战这一矛盾，通过平衡强大的技术能力和良好的开发者体验，Rust 让你可以选择控制低级细节（如内存使用），而无需承受与此类控制相关的所有麻烦。

## Rust 适合谁

Rust 因各种原因对许多人来说都是理想的选择。让我们看看几个最重要的群体。

### 开发团队

Rust 正被证明是一个高效的工具，用于在具有不同系统编程知识水平的大型开发团队之间进行协作。低级代码容易出现各种微妙的错误，在大多数其他语言中，这些错误只能通过广泛的测试和经验丰富的开发者仔细的代码审查来发现。在 Rust 中，编译器通过拒绝编译包含这些难以捉摸的错误（包括并发错误）的代码来扮演守门人的角色。通过与编译器合作，团队可以将时间集中在程序的逻辑上，而不是追踪错误。

Rust 还为系统编程世界带来了现代化的开发工具：

- Cargo，内置的依赖管理器和构建工具，使得在整个 Rust 生态系统中添加、编译和管理依赖变得轻松且一致。
- `rustfmt` 格式化工具确保开发者之间的代码风格一致。
- Rust 语言服务器为集成开发环境（IDE）提供代码补全和内联错误消息的集成支持。

通过使用 Rust 生态系统中的工具，开发者可以在编写系统级代码时保持高效。

### 学生

Rust 适合学生和那些有兴趣学习系统概念的人。使用 Rust，许多人学习了操作系统开发等主题。社区非常欢迎并乐于回答学生的问题。通过像本书这样的努力，Rust 团队希望让更多的人更容易接触系统概念，特别是那些刚接触编程的人。

### 公司

数百家大大小小的公司在生产环境中使用 Rust 来完成各种任务，包括命令行工具、Web 服务、DevOps 工具、嵌入式设备、音频和视频分析与转码、加密货币、生物信息学、搜索引擎、物联网应用、机器学习，甚至 Firefox 浏览器的主要部分。

### 开源开发者

Rust 适合那些想要构建 Rust 编程语言、社区、开发工具和库的人。我们很乐意让你为 Rust 语言做出贡献。

### 重视速度和稳定性的人

Rust 适合那些渴望语言速度和稳定性的人。所谓速度，我们既指 Rust 代码运行的速度，也指 Rust 让你编写程序的速度。Rust 编译器的检查确保了添加功能与重构时的稳定性。这与没有这些检查的语言中脆弱的遗留代码形成对比，开发者通常害怕修改这些代码。通过追求零成本抽象——将高级语言特性编译成底层代码，并且与手写的代码运行速度同样快——Rust 努力让代码安全而又快速。

Rust 语言希望支持许多其他用户；这里提到的只是一些较大的受益群体。总的来说，Rust 最大的雄心是通过消除程序员几十年来一直接受的权衡，让安全和生产力、速度和易用性可以兼得。试试 Rust，看看它的选择是否适合你。

## 本书适合谁

本书假设你已经用另一种编程语言编写过代码，但不对具体是哪种语言做任何假设。我们努力让来自各种编程背景的人都能广泛理解本书内容。我们不会花太多时间讨论编程是什么或如何思考它。如果你是编程新手，最好阅读专门提供给编程入门者的书籍。

## 如何使用本书

一般来说，本书假设你按照从前到后的顺序阅读。后面的章节建立在前面章节的概念之上，前面的章节可能不会深入探讨特定主题的细节，但会在后面的章节中重新讨论该主题。

你会在本书中找到两种类型的章节：概念章节和项目章节。在概念章节中，你将学习 Rust 的一个方面。在项目章节中，我们将一起构建小程序，应用你到目前为止所学的知识。第 2 章、第 12 章和第 21 章是项目章节；其余的是概念章节。

**第 1 章** 解释如何安装 Rust、如何编写 "Hello, world!" 程序，以及如何使用 Cargo（Rust 的包管理器和构建工具）。**第 2 章** 是用 Rust 编写程序的实践介绍，让你构建一个猜数字游戏。这里我们站在较高层次上介绍概念，后面的章节将提供更多细节。如果你想立即动手实践，第 2 章就是你的选择。如果你是一个特别细致的学习者，喜欢在继续下一步之前学习每一个细节，你可能想跳过第 2 章，直接进入 **第 3 章**，它涵盖了与其他编程语言类似的 Rust 特性；然后，当你想要应用所学细节进行项目实践时，可以返回第 2 章。

在 **第 4 章** 中，你将学习 Rust 的所有权系统。**第 5 章** 讨论结构体和方法。**第 6 章** 涵盖枚举、`match` 表达式以及 `if let` 和 `let...else` 控制流结构。你将使用结构体和枚举来创建自定义类型。

在 **第 7 章** 中，你将学习 Rust 的模块系统以及用于组织代码及其公共应用程序编程接口（API）的隐私规则。**第 8 章** 讨论标准库提供的一些常见集合数据结构：向量、字符串和哈希映射。**第 9 章** 探讨 Rust 的错误处理理念和技术。

**第 10 章** 深入探讨泛型、trait 和生命周期，它们使你能够定义适用于多种类型的代码。**第 11 章** 全部关于测试，即使有 Rust 的安全保证，测试也是确保程序逻辑正确的必要条件。在 **第 12 章** 中，我们将构建自己实现的 `grep` 命令行工具的功能子集，该工具用于在文件中搜索文本。为此，我们将使用前面章节中讨论的许多概念。

**第 13 章** 探讨闭包和迭代器：来自函数式编程语言的 Rust 特性。在 **第 14 章** 中，我们将更深入地研究 Cargo，并讨论与他人共享库的最佳实践。**第 15 章** 讨论标准库提供的智能指针以及启用其功能的 trait。

在 **第 16 章** 中，我们将介绍不同的并发编程模型，并讨论 Rust 如何帮助你无畏地进行多线程编程。在 **第 17 章** 中，我们在此基础上探索 Rust 的 async 和 await 语法，以及任务、future 和流，以及它们启用的轻量级并发模型。

**第 18 章** 探讨 Rust 习惯用法与你可能熟悉的面向对象编程原则的比较。**第 19 章** 是关于模式和模式匹配的参考，它们是在整个 Rust 程序中表达思想的强大方式。**第 20 章** 包含各种高级主题，包括不安全的 Rust、宏以及更多关于生命周期、trait、类型、函数和闭包的内容。

在 **第 21 章** 中，我们将完成一个项目，实现一个低级多线程 Web 服务器！

最后，一些附录以更像参考手册的格式包含有关语言的有用信息。**附录 A** 涵盖 Rust 的关键字，**附录 B** 涵盖 Rust 的运算符和符号，**附录 C** 涵盖标准库提供的可派生 trait，**附录 D** 涵盖一些有用的开发工具，**附录 E** 解释 Rust 版本。在 **附录 F** 中，你可以找到本书的翻译版本，在 **附录 G** 中，我们将介绍 Rust 是如何制作的以及 nightly Rust 是什么。

阅读本书没有错误的方式：如果你想跳过前面的内容，那就去做吧！如果遇到任何困惑，你可能需要跳回到前面的章节。但无论什么方式对你有效就怎么做。
